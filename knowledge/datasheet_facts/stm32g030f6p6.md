- "This is information on a product in full production" (Rev 6, jun 2025, título indexado). — VERIFIED (título del documento)
- LCSC 2026-07-07: C724040 (tube) stock 3394, 0.9535 USD q1; C529330 (T&R) stock 6046, 0.8612 USD q1. API LCSC. — VERIFIED

## Alimentación
- VDD operativo 2.0–3.6 V. VDDA y VDDIO1 internamente al mismo pin VDD/VDDA en este package. [DS12991 §3.7.1, p.14] — VERIFIED
- Desacoplo requerido en el par VDD/VDDA–VSS/VSSA: **1 × 100 nF + 1 × 4.7 µF cerámicos**,
  "as close as possible to, or below, the appropriate pins". [DS12991 §5.1.6, Fig. 9, p.39] — VERIFIED
- "The 100 nF capacitor should be ceramic (good quality) and placed as close as possible to the chip." [DS12991 p.70] — VERIFIED

## NRST
- Pull-up interno permanente RPU = 25–55 kΩ (40 k typ). [DS12991 Table 52, p.65] — VERIFIED
- Protección recomendada: **condensador 0.1 µF a GND, lo más cerca posible del dispositivo**;
  no se requiere resistencia externa. [DS12991 Fig. 19, p.66] — VERIFIED
- Pulso filtrado < 70 ns; pulso garantizado no filtrado ≥ 350 ns. [Table 52, p.65] — VERIFIED

## BOOT0 / nBOOT_SEL (estado de fábrica)
- El pin de boot (PA14-BOOT0) está compartido con GPIO y "can be enabled through the boot
  selector option bit". [DS12991 §3.5, p.14] — VERIFIED
- FLASH_OPTR bit 24 `nBOOT_SEL`: 0 = BOOT0 por pin (modo legacy); **1 = BOOT0 por option bit
  nBOOT0** (el pin se ignora). [RM0454 Rev 2, p.74] — VERIFIED
- **"The boot option is configured by default through option bytes"** — de fábrica no se muestrea el
  pin BOOT0; solo se usa el pin si el usuario reprograma la opción. [AN5096 §Boot, p.27] — VERIFIED
- **Empty check**: si la flash está virgen (0x08000000 == 0xFFFFFFFF) el dispositivo selecciona el
  bootloader de sistema en vez de la flash principal → un chip nuevo arranca en bootloader y es
  programable; tras programar por SWD se ejecuta el código de usuario. [RM0454 Rev 2, §2.5 p.47 y §3.3.2 p.50] — VERIFIED
- Consecuencia para el esquemático: **no se necesita strap/jumper en BOOT0**; PA14 queda dedicado
  a SWCLK. Bring-up por SWD garantizado (NRST en el header). — INFERRED (de los tres hechos anteriores)

## SWD
- PA13 = SWDIO (pin 18), PA14 = SWCLK (pin 19); configurados como AF de debug tras reset con
  pull-up (PA13) / pull-down (PA14) internos activos. [Table 12 nota 5, p.34] — VERIFIED
